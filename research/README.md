# Исследование: можно ли сделать бота из макро + ICT

Два бэктеста без подгонки: все пороги взяты из терминала (TOPDOWN, правила индикатора ICT-QPS v21) и не оптимизировались.
Запуск: `node research/step1_regime.js`, затем `node research/step2_entries.js`. Подробные цифры — в `results/*.json`.

## Шаг 1. Макро-режим на дневках (2008 → октябрь 2026)

Nasdaq-100 и S&P 500, 10 макро-факторов TOPDOWN (ликвидность ФРС, 10Y, доллар, VIX, 2Y против ставки, реальная
доходность, тренд инфляции, кредитный спред BAA−10Y, структура VIX, NFCI). Каждый ряд — с задержкой публикации.
Правила взяты из 2008–2016, проверка — 2017–2026 (новые для правил данные). Издержки 2 б.п. на сделку.

| Nasdaq-100, 2017–2026 (проверка) | Доходность в год | Sharpe | Макс. просадка | В рынке |
|---|---|---|---|---|
| Купить и держать | 20.8% | 0.94 | −35.6% | 100% |
| Тренд (цена > SMA50) | 13.0% | 0.91 | −19.4% | 72% |
| Тренд + макро-фильтр (счёт ≥ 0) | 13.6% | **1.06** | −18.9% | 60% |
| Тренд + размер по макро | 11.7% | 1.04 | −18.7% | 66% |

S&P 500 за 2017–2026: «тренд + размер по макро» — Sharpe 0.98 против 0.78 у «купить и держать», просадка −9.3% против −33.9%.

**Вывод.** Макро-счёт **не предсказывает направление**: доходность следующих 20 дней при счёте ≥ +3 и ≤ −3 почти
одинаковая, ни один фактор по отдельности не значим (|t| < 1.4). Но как **фильтр риска** он работает: срезает просадки
и волатильность, улучшает доходность на единицу риска, хотя общая доходность ниже, чем у «купить и держать».
Применение — размер позиции и защита счёта (важно для трейлинг-просадки проп-фирмы), а не сигнал входа.

## Шаг 2. ICT-входы как реальные сделки (перпы QQQ/SPY = NQ/ES, апрель → октябрь 2026, часы CME)

Каждое первое касание RB / OB / FVG (15m) и каждый вход «свип + реклейм» по открытиям 00:00 / 09:30 / 10:00 NY:
вход на уровне, стоп за тенью / дальней границей, цель 2R (1R и 3R для устойчивости), выход по времени через 4 часа.
~3000 сделок на каждом инструменте.

| NQ, издержки CME | Сделок | Средний результат | t |
|---|---|---|---|
| RB / OB / FVG — все | 2478 | −0.18…−0.29R | значимо < 0 |
| FVG по тренду в киллзону | 287 | −0.03R | ≈ 0 |
| FVG против тренда | 330 | −0.50R | значимо < 0 |
| **Открытие 00:00 — все** | 245 | **+0.13R** | 1.4 |
| **Открытие 00:00 по тренду в киллзону** | 43 | **+0.33R** | 1.5 |

ES: открытие 10:00 по тренду — +0.30R (n=41, t=1.4); открытие 00:00 по тренду в киллзону — +0.30R (n=42, t=1.3).

**Выводы.**
1. Зоны RB / OB / FVG как механический вход **убыточны** после издержек, даже с фильтрами тренда, киллзон и макро.
   То, что зона «дала реакцию» (метрика ICT-панели), не значит, что сделка с таким стопом прибыльна: реакция не учитывает,
   что цена до неё успевает выбить узкий стоп.
2. Вход против тренда — худшее, что можно делать (FVG против тренда −0.5R на сделку).
3. На перпах Binance (комиссия ~0.07% за круг) всё уходит в −1R: стопы у этих уровней слишком узкие для таких издержек.
   Торговать это можно только фьючерсами CME (NQ/MNQ), где издержки в ~20 раз меньше.
4. **Кандидаты:** вход «свип + реклейм» от открытия 00:00 NY по тренду (NQ, обе половины периода в плюсе) и от 10:00 по
   тренду (ES). Но t ≈ 1.3–1.5 при ~40 вариантах проверки — это ещё не доказательство, такой результат может быть
   случайностью. Нужна проверка вперёд (paper trading) на 60–100 сигналов.
5. Макро-фильтр внутри дня не помог.

## Что из этого следует для бота

- Полностью автоматический бот на зонах ICT — **нет**: отрицательное ожидание после издержек.
- Реалистичная схема: **макро → размер позиции**, **тренд → разрешённое направление**, **вход только по кандидатам
  (открытия 00:00 / 10:00 с реклеймом)**, **запреты** вокруг CPI / NFP / FOMC и отчётов гигантов.
- Следующий шаг — сигнальный бот без исполнения: терминал присылает сигнал (вход, стоп, цель, контракты MNQ/NQ),
  ведёт журнал и считает результат вперёд. Через 2–3 месяца — решение по реальным цифрам. Для Apex это полуавтомат
  (вход делает человек), что соответствует их правилам.

Ограничения: 6 месяцев внутридневной истории (бесплатные данные), объём для фильтров — с перпа Binance, проскальзывание
моделируется грубо (~1 пункт NQ на круг), в одной свече «стоп и цель» считается стопом.
